活到黎明 · 玩法说明

  • 目标：活到 12 分钟，击败降临的「永夜化身」即迎来黎明（15 分钟硬上限，终局 Boss 仍存活则判负）。途中约每 3 分钟一位 Boss：血色男爵 3′ / 苍白女王 6′ / 永夜君王 9′；第 9 分钟永夜加深，敌人变强并解锁暗影猎手、石像鬼。
  • 血裔：开局可在「血裔选择」中挑选初始角色，6 种血裔起手武器与天赋各异（流浪者免费；圣徒 / 狂战 / 雷巫 / 嗜血者花灵魂解锁；永夜使徒为隐藏高难流派）。
  • 移动：WASD / 方向键；手机触屏拖动。你只管走位，活下去。
  • 攻击：武器自动索敌开火，无需手动瞄准。共 16 把武器——8 把基础（飞刃 / 圣水 / 战斧 / 雷霆 / 光环 / 长鞭 / 圣印 / 亡魂镰刀）+ 8 把神器原型（星陨弩·追踪 / 断罪之锋·重刺 / 幻影裂片·分裂 / 守护结晶·哨卫 / 回响哨卫·环绕 / 碎甲重锤·冲击 / 噬血荆棘·吸血 / 镇魂钟鸣·陷阱），外加 13 种被动。
  • 升级：拾取掉落的灵魂宝石积累经验，升级时三选一强化（满槽后只能升级已有装备）。
  • 进化：武器升满级并持有对应被动，开启 Boss 宝箱即可进化为更强神器——18 套配方等你集齐（神器图鉴与升级界面均标注配方）。
  • 觉醒机制：神器进化后，若继续持有其配对被动，将恒常触发觉醒专属机制（如星陨弩暴击迸射追命碎片、噬血荆棘吸血化热成盾）——投资该被动即解锁更强形态。
  • 词缀怪：部分敌人带词缀，需针对性应对——狼群(琥珀金,群体包抄) / 爆破(橙,死亡爆炸) / 护盾(蓝,大幅减伤)。
  • 长远：阵亡后获得灵魂，在「灵魂祭坛」永久强化（生命 / 伤害 / 移速 / 灵魂获取 / 双生武装 / 武器·被动槽扩容）。
  • 灵魂树：主菜单的「灵魂树」消耗灵魂点亮 5 大分支天赋（征伐 / 血裔协同 / 永夜抗性 / 灵魂经济 / 通用机能），可随时重置（返还净额扣 5% 手续费），构建并迭代你的专属 build。
